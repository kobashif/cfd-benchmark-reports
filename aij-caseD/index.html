0. 要旨

AIJ 風環境ベンチマーク ケース D（高層棟を含む街区）を定常 RANS で解き、歩行者高さの風洞実験と照合した。本版に載せたのは 3 風向（0°・22.5°・45°）である。

  • 3 風向のうち 3 風向で、定常計算の報告する量が止まった（3.1 節）。到達状態は、判定を満たして停止 0 風向、解は定常（残差は判定値に届かない）3 風向。引用するときはこの区別を落とさないこと。
  • 実測との相関係数は r = 0.76〜0.87、±25 % 以内に入る測点の割合は 55〜64 %。
  • 計算は実測より小さい側に偏る（偏り -0.120〜-0.089）。風向 0° で測る量を計算と揃えると、この偏りはほぼ消える（4.2 節）。
  • 乱流エネルギーは計算が実測より小さい（4.3 節）。

1. 対象と実験

高層棟 1 棟（0.0625 m 角・高さ 0.250 m）と、その周囲に並ぶ低層棟 82 棟（高さ 0.025 m）からなる街区。座標系はデータセットのまま用いている。

実測は歩行者高さ z = 0.005 m の水平面。測器は 2 種類ある。

  • サーミスタ（各風向 66 点）：無指向性で、平均スカラー風速 Vs = ⟨|u|⟩ を返す
  • 熱線（風向 0° のみ 33 点）：3 成分と乱流エネルギー k を与える

基準風速 UH = 6.65 m/s は高層棟の高さの接近流。

どのケース D か。本書が解いたのは AIJ UWE ベンチマークデータセット [1][4] の Case D（高層棟を含む街区）である。Yoshie ほか (2007) [6] が整理した旧ベンチマークとは別のデータセットなので、測点数や配置を旧ベンチマークと比べることはできない。

寸法は模型のまま示す。データセットは模型寸法で定義されており、実寸の縮尺は規定されていない。実寸に直すときは縮尺を掛ける（例：1/400 とみなせば高層棟の高さ 0.250 m は 100 m、評価高さ 0.005 m は 2 m にあたる）。レイノルズ数に依らない範囲での相似を前提とする。

2.1 乱流モデル

乱流モデルは標準 k-ε とした。

根拠は、単体の建物で乱流モデルを比べた結果である。単体角柱（ケース A）と単体の板状建物（ケース B）を、同じ格子・同じ止め方で 7 種のモデルで解き、判定を満たして止まったモデルのうち全測点の風速の RMSE が最小だったのは、ケース A では 標準 k-ε（0.1351、3 / 7 モデルが判定を満たした）、ケース B では 標準 k-ε（0.1388、同 4 / 7）だった（それぞれの報告書 版 2.1）。

版 2.3 までの計算は、Kato–Launder 型 k-ε を本計算で実装したもので解いていた。その実装は k の式と ε の式の両方で生成項を置き換え、上限を実質なしとしたもので、原典 [3] の形と異なるため、版 3.0 で標準 k-ε に替えて 3 風向と格子依存性の計算をすべて解き直した。版 2.3 までの数値とは比べられない。本版の設定で、ケース D そのものについて乱流モデルを比べ直してはいない。

地表面の粗度条件は、乱流モデルを替えても決め直していない。建物を置かない流れ（地面の上を一様に流れる境界層）では、Kato–Launder 型と標準 k-ε は同じ式になる（単純なせん断流ではひずみと渦度の大きさが等しいため）。ケース C で建物を置かない計算を2 つのモデルで解いて確かめると、歩行者高さの風速比の差は最大 1.7e-04 だった（ケース C の報告書 2.1 節）。

3. 検証（Verification）

3.1 反復収束

計算の止め方は、全風向で同じ規則を当てた。5,000 反復で最初の判定をし、それより前には止めない。

  1. 報告する量（測点の風速比）の、500 反復離れた 2 時刻の差が、全測点の最大で 0.005 未満、中央値で 0.001 未満なら止める
  2. 止まっていなければ、圧力の残差がまだ下がっているうちは 1,500 反復ずつ延ばす（上限 11,000 反復）。残差が横ばいなら止めて「打ち切り」とする

止めた計算は、残差の水準（最初の圧力解の初期残差が 5×10−4 以下、U・k・ε が 10−4 以下）も満たせば「判定を満たして停止」、満たさなければ「解は定常（残差は判定値に届かない）」と書き分ける。

速度の残差は判定に使わない。成分ごとに成分の大きさで割って求めるので、流れのほとんど無い成分では残差が大きく出る。

3.4 格子依存性

風向 0° を、格子だけを変えた 3 通りで解いた。地表の粗度条件・流入・乱流モデル・離散化・緩和係数はすべて同じ値に固定しており、高層棟まわりの細分の範囲も 3 通りで同じにしてある（細分の箱を建物の面に合わせた。合わせないと粗い格子で非直交度が 80° 近くまで悪化し、格子の質の差が結果に混ざる）。止め方は本計算と同じ共通の規則である。

圧力の初期残差は 3 通りとも判定値 5×10−4 以下である。格子「粗い」は、報告する量の動きが最大 0.0104 と判定値 0.005 を超えたまま、5,000 反復で「打ち切り（残差が横ばい）」とした。この格子の値は止めた時刻のもので、まだ動いている。格子幅の比（セル数の比の 3 乗根）は 粗→中 1.150、中→細 1.169。

RMSE は 0.1558 → 0.1488 → 0.1551 と動いた（1 つ細かくしたときの動きは -0.0070 と +0.0063）。細かくするほど単調に近づく形にはなっておらず、中くらいの格子で最小になる。偏りは -0.119〜-0.113 でほとんど動かない。

単調に動いていないので GCI は出せない（単調に近づいていない（R = -0.889 が 0〜1 の外））。格子による不確かさの目安には、1 つ細かくしたときの動きの大きい方（0.0070、風速比にして 0.7 %）を使う。本書で条件どうしの差を論じるときは、この大きさを超えているかで判断する。

測ったのは風向 0° だけである。22.5°・45° では格子を変えた計算をしていない。

4.1 偏りの向き

計算は実測より小さい側に偏る（-0.120〜-0.089）。サーミスタが返すのは平均スカラー風速 ⟨|u|⟩、定常 RANS が出すのは 平均風速ベクトルの大きさ |⟨u⟩| であり、変動のある場所では前者が大きいので、原理的に負へ寄る [2][4]。次節で、同じ面を熱線で測った実測を使ってこれを確かめる。

4.2 測定量の違い（風向 0°）

風向 0° では、同じ面を 2 種類の測器で測った実測がある。サーミスタは無指向性で平均スカラー風速 Vs = ⟨|u|⟩ を返し、熱線は 3 成分から平均風速ベクトルの大きさ |⟨u⟩| を与える。定常 RANS が出すのは後者である。

表 7　風向 0°：測る量を揃えたときの一致
実測の量点数傾き相関係数 rRMSE偏り±25 % 以内
サーミスタ Vs = ⟨|u|⟩（全測点）660.7600.7600.158-0.12055 %
サーミスタ Vs（熱線と同じ測点）330.7600.7600.158-0.12055 %
熱線 |⟨u⟩|（計算と同じ量・同じ測点）330.8070.8770.080-0.01861 %

サーミスタの 66 点のうち独立な点は 33（残りは y 鏡像の複製）で、その独立な 33 点が熱線の測点と同じ位置にある。上 2 行の値が一致するのはこのためで、3 行目との差は測点ではなく測る量の違いによる。

測る量を計算と揃えると偏りはほぼ消える（偏り -0.120 → -0.018、RMSE 0.158 → 0.080）。実測どうしの比 Vs / |⟨u⟩| の中央値は 1.308 で、この差は補正で埋める前に測器の定義で説明が付く。

4.3 乱流エネルギーの限界

熱線は乱流エネルギー k も与える。無次元化した k / UH2 で比べると、相関はほとんど無く（r = -0.224、33 点）、計算は小さい側に偏る（偏り -0.0062）。

実測で k が大きい上位 4 分の 1 の測点（9 点。高層棟の後流にあたる）では、実測の中央値 1.63 m2/s2 に対し計算は 0.59 m2/s2 で、64 % 少ない。

本版の k は突風や変動の大きさの指標に使えない。報告しているのは平均風速の分布であり、変動の統計量は与えていない。

収束の良さと、実測との一致は別である。3.1 節の判定を満たしたことは、その設定の解が止まっていることを示すだけで、実測に合っていることを示すものではない。

図は定常 RANS の平均場である。瞬間の風や突風は表していない。変動の大きさに関わる乱流エネルギーは実測より小さい（4.3 節）ため、この図から突風の強さを読み取ることはできない。

6. 結論

  1. 収束。3 風向を同じ規則で止めて照合し、3 風向で報告する量が止まった。残差の水準まで満たした風向は無く、いずれも「解は定常（残差は判定値に届かない）」である（3.1 節）。緩和係数を変えて回し直していないので、残差が届かないのが計算の性質なのかは分からない（「満たさなかった」のであって「満たしえない」とは言えない）。
  2. 風速。相関係数 0.76〜0.87、±25 % 以内 55〜64 %、偏り -0.120〜-0.089（計算が小さい側）。風向 0° で測る量を計算とそろえると、偏りはほぼ消える（4.2 節）。偏りの主な原因は、実測が平均スカラー風速を返すのに対し定常 RANS が平均風速ベクトルの大きさを与えることにある。
  3. 実測を再現できたか。全 198 点で相関係数 0.85・RMSE 0.147・偏り -0.106、±25 % 以内は 58 %である。風が強い所ほどよく合う。実測が 0.7 U(H) 以上の 20 点では ±25 % 以内 100 %、0.5 未満の 129 点では 46 % にとどまる。したがって、強風部の風速比は再現できているが、低風速域は相対誤差が大きいまま残っている。これが残った課題である（6.1 節）。
  4. 乱流エネルギー。熱線の k と比べると相関はほとんど無く、高層棟の後流では計算が実測より 6 割以上小さい（4.3 節）。本版の k は、突風や変動の大きさの指標には使えない。
  5. 格子。風向 0° を、粗度条件をそろえたまま格子だけ変えた 3 通り（50〜122 万セル）で解いた（3.4 節）。RMSE は 0.1558 → 0.1488 → 0.1551 で、細かくするほど良くなる形にはならず、中くらいの格子で最小になる。偏りはほとんど動かない。単調でないため GCI は出せない。格子による不確かさの目安は1 つ細かくしたときの動き 0.0070（風速比の 0.7 %）とする。測ったのは 3 風向のうち 0° だけである。
  6. 実務への適用。高層棟まわりで風が強くなる場所の把握と、同じ設定どうしの相対比較には使える。一方、計算値をそのまま風環境の判定に当てはめるのは危険側で、判定の境目では余裕を見る必要がある。最大風速・超過確率、通風・拡散の評価には本版の結果は使えない（6.1・6.2 節）。
  7. 適用範囲。本書の結果は高層棟＋低層街区・風向 3 通りの定常 RANSの検証であり、他の街区形状、非定常な変動、最大風速、超過確率には直接は当てはめられない。

強風部の一致が弱風部より明らかに良い。偏りは範囲によらずほぼ同じ大きさなので、相対誤差の違いは、その差を何で割るかの違いから来ている。低層街区の中のような弱風部が効く用途（滞留・拡散・体感）では、下の 2 行の方が実態に近い。

課題は 3 つある。

  1. 全域で計算が実測より小さい。偏りは範囲ごとに -0.117〜-0.088 で、風速比の大小にあまり依存しない。風向 0° で測る量を計算とそろえると、この偏りはほぼ消える（4.2 節）ので、主な原因は、実測が平均スカラー風速を返すのに対し定常 RANS が平均風速ベクトルの大きさを与える違いにある。ただしそのまま判定に使えば風を小さく見積もる側になる。
  2. 乱流エネルギーが足りない。高層棟の後流では計算が実測より 6 割以上小さく、（4.3 節）。変動の大きさを扱う用途には使えない。
  3. 格子による不確かさ。格子による不確かさは風向 0° で測った（3.4 節）。RMSE の動きは 0.0070（風速比の 0.7 %）で、偏りはほとんど動かない。つまり計算が実測より小さく出るのは格子の粗さのせいではない。残る 2 風向では測っていない。

6.2 実務で使うときの目安

使える場面。高層棟まわりで風が強くなる場所の把握、風向ごとの傾向の比較、同じ格子・同じ設定で作った案どうしの相対比較。強風部（実測 0.7 U(H) 以上）では ±25 % 以内 100 %・±10 % 以内 45 % である。

使えない場面。

  • 計算値をそのまま風環境の判定に当てはめること。全域で小さい側に出るので、そのままでは危険側になる。
  • 最大風速・超過確率。定常 RANS は変動の統計量を与えない。本ケースは 3 風向とも残差が判定値に届かないまま報告する量が止まった状態で止めている（3.1 節）。
  • 通風・拡散のように乱れの量が効く評価。後流の k が大きく不足する。
  • 風向どうしの小さい差を根拠にした順位付け。格子による不確かさは風向 0° でしか測っていない（3.4 節）。

格子の目安。本ケースの格子は 約 117 万セル で、高層棟まわりに水平方向の細分を加えている（2 章）。本ケース・本領域・本離散化条件では、約 76 万セルから 122 万セルへ細かくしても、RMSE の動きは 0.0063（風速比の 0.6 %）にとどまった（3.4 節）。偏り（0.119 前後）の方がはるかに大きいので、格子を細かくしても実測との差は埋まらない。

7. 適用範囲および留意事項

  • 定常 RANS の結果である。変動の統計量（最大風速・超過確率）は与えない。
  • 乱流エネルギーは実測より小さく、突風の指標には使えない（4.3 節）。
  • 格子依存性は風向 0° でのみ測った（3.4 節）。22.5°・45° には当てはめていない。
  • 収束判定を満たさない風向の値は、止めた時刻の場から出したものである（3.1 節）。

図の作り方。断面や水平面の図は、計算の場を面で取り出した生データ（OpenFOAM の surfaces 機能、raw 形式）から matplotlib で描いている。ParaView などの可視化ソフトは使っていない。色の段階は図ごとに題に示した範囲で等間隔に切り、断面の位置は図の題に書いたとおりである。
