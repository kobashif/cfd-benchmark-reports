# CFD 検証記録

OpenFOAM による室内気流・通風 CFD の検証レポート。
公表されている実験値との比較を、格子・乱流モデル・数値設定まで遡って確定させたもの。

**https://kobashif.github.io/cfd-benchmark-reports/**

| レポート | 対象 | 比較先 |
|---|---|---|
| [通風ベンチマーク](crossvent/) | 通風（等温） | 空気調和・衛生工学会 CFD ガイドブック 4.5 節 風洞実験 |
| [Annex 20 室内気流](annex20-2d/) | 室内気流（等温） | IEA Annex 20 二次元テストケース 公表 LDV 実測値 |
| [Annex 20 テストケース E](annex20-caseE/) | 混合対流（非等温） | IEA Annex 20 Subtask 1 報告書、実測 3 機関 |

## 資料の取り扱い

第三者の資料（書籍・報告書・実験データ）は**再配布していません**。
各レポートには出典を明記し、必要な数値のみを引用しています。

計算ファイルとスクリプトは非公開リポジトリで管理しており、このリポジトリには
**レポート（HTML・図・動画）のみ**を置いています。
